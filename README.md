## 🛠️ 개발 배경

- Unreal Engine 5와 Gameplay Ability System(GAS)을 이용한 시스템 아키텍처 경험 확보
- 실시간 멀티플레이와 데디케이티드 서버 환경 구축 경험 습득
- Git, Jira, 코드 리뷰 기반의 협업 개발 프로세스 경험
- 배틀로얄 장르의 핵심 시스템(파밍, 자기장, 차량, 무기 등) 구조 분석 및 구현 능력 향상

## 🎯 개발 목표 및 내용

- PUBG 스타일의 배틀로얄 게임 시스템 구현 (파밍, 자기장, 레드존, 보급 등)
- Listen Server → Dedicated Server 전환 기반 멀티플레이 구현
- Unreal GAS 기반 능력 시스템 구성 및 HUD 연동
- AttributeSet을 활용한 체력, 스태미너 등의 수치 동기화 처리
- 랜드스케이프 및 하이트맵을 활용한 지형 생성 + PCG 기반 마을 자동 배치
- Git Flow 기반 브랜치 전략으로 협업 관리 및 병합 체계화
